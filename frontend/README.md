# Frontend - Biblioteca Digital de Logística Pública

Esta pasta reúne duas entregas independentes da interface:

- `html/`: versão estática, sem etapa de compilação, pronta para abrir no navegador.
- `nextjs/`: cópia executável da aplicação Next.js/React institucional desenvolvida para a biblioteca.

A aplicação publicada na Vercel continua na raiz do repositório. Ela não foi movida para preservar a configuração de produção existente.
