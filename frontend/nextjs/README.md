# Versão Next.js / React

Espelho da interface institucional implementada com Next.js 16 App Router, React e Tailwind CSS.

## Executar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

O projeto ativo usado no deploy permanece na raiz do repositório; esta pasta é uma entrega separada do frontend para consulta e distribuição.
